
# Superstore Sales & Profit Analysis Dashboard

## Project Overview

This project is an interactive Power BI dashboard designed to analyze sales, profit, products, customers, and regional performance using the Superstore dataset.

The dashboard provides an overview of business performance and allows users to explore the data through interactive filters and visualizations.

## Tools Used

* Power BI
* DAX
* Data Visualization
* Data Analysis

## Key KPIs

* Total Sales
* Total Profit
* Total Orders
* Total Quantity
* Profit Margin

## Dashboard Pages

### 1. Sales Overview

This page provides a high-level overview of business performance, including key KPIs and analysis by category, region, and year.

### 2. Sales & Profit Analysis

This page analyzes sales and profit trends and compares profitability across categories and sub-categories.

### 3. Product & Customer Analysis

This page focuses on product performance, customer segments, top products by sales and profit, and shipping modes.

## Key Features

* Interactive slicers and filters
* DAX measures for business KPIs
* Sales and profit analysis
* Regional and category analysis
* Top 10 products analysis
* Multi-page interactive dashboard

## Project File

The Power BI dashboard file is included in this repository as a `.pbix` file.
